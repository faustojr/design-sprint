# 🚀 Começando com o GymApp

## Instalação Rápida

### 1. Clone ou acesse o repositório
```bash
cd gym-app
```

### 2. Instale as dependências
```bash
npm install
```

### 3. Inicie o servidor de desenvolvimento
```bash
npm run dev
```

### 4. Abra no navegador
```
http://localhost:5173
```

## 📱 Como Usar o App

### Tela Principal
1. Veja sua rotina semanal com 4 dias de treino
2. Clique em qualquer dia para ver os exercícios
3. Cada dia tem uma cor específica para fácil identificação

### Durante o Treino
1. Selecione o dia do treino
2. Veja a animação de cada exercício
3. Realize o número de séries e repetições indicadas
4. Marque o exercício como completo (✓)
5. Siga para o próximo exercício

### Informações do Exercício
- **Séries**: Quantas vezes você vai repetir o movimento
- **Repetições**: Quantas vezes em cada série
- **Animação**: Veja como fazer o movimento correto
- **Dicas**: Conselhos importantes para a execução

## ⏱️ Tempo de Treino Estimado

Cada dia leva aproximadamente:
- **Peito Day**: ~16 minutos
- **Costas Day**: ~16 minutos
- **Ombros Day**: ~14 minutos
- **Pernas Day**: ~20 minutos

*Adicione 10 minutos para aquecimento e alongamento*

## 💪 Dicas para Melhor Aproveitamento

### Antes do Treino
- [ ] Durma bem a noite anterior
- [ ] Coma algo leve 30-60 min antes
- [ ] Aqueça-se por 5-10 minutos

### Durante o Treino
- [ ] Mantenha boa hidratação
- [ ] Controle a velocidade do movimento
- [ ] Descanse 60-90 segundos entre séries
- [ ] Respeite seus limites

### Depois do Treino
- [ ] Alongue-se por 10 minutos
- [ ] Hidrate-se bem
- [ ] Coma proteína e carboidratos
- [ ] Durma o suficiente para recuperação

## 📊 Progressão de Treino

### Semana 1-2: Adaptação
- Use pesos leves
- Aprenda a forma correta
- Aumente o volume gradualmente

### Semana 3-4: Consolidação
- Mantenha os mesmos pesos
- Aumente as repetições
- Foque na qualidade

### Semana 5+: Progressão
- Aumente os pesos em pequenos incrementos
- Mantenha o volume
- Desafie-se gradualmente

## 🎯 Metas Realistas

### Curto Prazo (1 mês)
- Adaptar-se à rotina
- Aprender a forma correta
- Aumentar resistência

### Médio Prazo (3 meses)
- Notar mudanças visuais
- Aumentar força em 15-20%
- Melhorar disposição

### Longo Prazo (6+ meses)
- Transformação corporal significativa
- Aumento notável de força
- Hábito estabelecido

## 🚨 Quando Parar o Treino

Procure um médico se sentir:
- Dor aguda ou punzante
- Tontura ou vertigem
- Dificuldade para respirar
- Qualquer desconforto anormal

## 🔧 Troubleshooting

### App não carrega
```bash
# Limpe o cache e reinstale
npm clean cache --force
npm install
npm run dev
```

### Animações não aparecem
- Verifique se JavaScript está habilitado
- Tente atualizar a página
- Use um navegador moderno (Chrome, Firefox, Safari, Edge)

### Problema de responsividade
- Abra o DevTools (F12)
- Verifique o modo responsivo
- Ajuste o zoom se necessário
